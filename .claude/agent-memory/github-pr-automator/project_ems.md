EmpSAS is a full-stack Employee Management System with a Spring Boot 3.2 (Java 17) backend and React 18 / MUI v5 frontend. All 10 modules are built. The GitHub repo is https://github.com/sonikanta837-cloud/EduSas.git on the `master` branch (master is both the working and base branch — there is no separate `main`).

**Why:** Single active developer project; master is the integration branch.

**How to apply:** PRs should always target `master`, not `main`. Push to `origin master` directly.
